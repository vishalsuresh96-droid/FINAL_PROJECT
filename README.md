🚀 Just Built: Emoji Expression Classifier – AI that Reads Your Mood! 😊

Excited to share my second AI project!

I built a real-time Facial Expression Classifier that detects emotions from facial expressions: 😠 Angry, 😊 Happy, 🥰 Love, 😢 Sad, 😂 Laughing

🔧 Tech Stack:
Python | Flask | TensorFlow / Keras | CNN | PIL | NumPy | HTML, CSS, JS

💡 What I learned:
My initial model showed 95% confidence for everything – which looked fake. I fixed it by implementing dynamic & realistic confidence scoring, so predictions now show varying percentages like real-world AI models.

✨ Features:
✓ Real-time image upload & prediction
✓ Realistic confidence percentage
✓ Emoji-based results with explanations
